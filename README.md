# Kleinia

**The first Linux distribution that is agentic from the kernel up.**

Kleinia is an agentic Linux distribution built on Fedora atomic. Agents are first-class kernel objects — each one gets identity, permissions, quotas and context. The OS runs agents, and agents run the OS: agent for OS, OS for agent, like the inside and outside of a Klein bottle.

This repository is the **assembly recipe** of the distribution — the image build that composes the custom ACB kernel and the GNOME atomic desktop into the bootable image and the live ISO.
